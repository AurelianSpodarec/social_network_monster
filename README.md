## About The Project

[![Product Name Screen Shot][product-screenshot]](https://example.com)

Social network monster is build so you can share your moments with friends. Login to the webapp and invite your frineds. Its just like facebook! 

I've build the project for fun, doing the front-end and the back-end, so called full-stack.

Some things you can do is:

Login
Register
Add frineds
Build RESTful API

## Getting Started

To get started you will need to have already installed MongoDB and NodeJS.

### Prerequisites

* npm
```sh
npm install npm@latest -g
```

### Installation

2. Clone the repo
```sh
git clone https://github.com/AurelianSpodarec/social_network_monster
```
3. Install NPM packages
```sh
npm install
```
